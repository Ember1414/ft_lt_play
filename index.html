关于本项目

一个纯前端的信号与系统交互式可视化学习工具，覆盖：

  • 傅立叶级数 · 画圈套画圈动画 / 谐波分解
  • 傅立叶变换 · 时域↔频域联动 / 卷积定理
  • 拉普拉斯变换 · s 平面 / 极点-零点与稳定性
  • 系统分析 · 传递函数 → 波特图 / 阶跃响应
  • 公式推导 · 逐步演算 / 性质表
  • 交互求解 · 输入表达式 / 手绘 / 语音

无服务端、无上传，全部在浏览器本地计算。部署于 Cloudflare Pages。
