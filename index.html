信号与控制实验平台

从左侧选择一个模块开始探索，动鼠标、拖滑块、看反馈。

帮助 · 如何使用

  • 工作台：平台入口。「快速开始」任一模板即创建实验并打开对应模块；实验自动保存在浏览器本地（不上传），支持搜索 / 收藏 / 重命名 / 复制 / 快照恢复 / JSON 导出导入 / 版本化分享码（PX1.…，含数据校验）。
  • 结果工具栏：系统分析与 Z 变换模块顶部一排共用操作——💾 保存实验（打快照）· ⧉ 复制 · ↺ 重置到上次保存 · 🔗 分享（版本化链接）· 🖼 PNG · 📊 CSV · 📄 JSON 导出。
  • 导航分组：工作台 → 学习（信号与变换：傅立叶级数/傅立叶变换/拉普拉斯/Z 变换）→ 分析（控制系统：系统分析/PID 整定/系统框图）→ 工具（交互求解/公式推导）。顶栏显示当前分组。
  • 通用图表操作：所有图表随窗口自动适配尺寸，滚轮缩放、拖拽平移、双击复位、悬停读数（手机：双指捏合缩放、单指平移）。折叠面板点标题展开。手机端 ☰ 打开侧边栏；快捷键：空格 播放/暂停 · R 重置 · F 逐帧 · T 切主题 · 1–9 切模块 · Esc 关闭弹层（仅对含动画的模块生效）。
  • 傅立叶级数：圆套圈动画（预设/手绘形状）；谐波叠加支持 2D/3D 瀑布切换——3D 视图拖动仅旋转、滚轮/捏合缩放、双击复位，向下滑动不会误移动坐标。🔗 分享 / 📷 PNG。
  • 傅立叶变换：常见函数时域↔频域联动；卷积定理动画（播放速度可调）；采样与重建页签演示奈奎斯特判据、混叠与零阶保持/线性/sinc 重建（重建波形与采样点严格对齐）。
  • 拉普拉斯变换：预设/手动 H(s)（符号键盘 + 输入即自动应用 + 实时阶跃预览）/零极点/s 平面点选，ROC 与稳定性联动，留数法解析解对照。s 平面为等比例坐标，支持触屏（单指平移、双指捏合缩放、长按菜单）。
  • Z 变换（新）：z 域传函 H(z)，z 平面零极点与单位圆稳定性判据、ROC、频率响应 H(e^{jω})、冲激/阶跃响应递推；配套公式推导（公式推导页含 Z 性质表/变换对/推导步骤）。z 平面支持触屏（单指平移、双指捏合缩放、长按菜单增删零极点）。
  • 模型库：各模块的 💾 保存 可把当前传函 / 框图存入本地模型库（浏览器 localStorage，最多 20 个），「我的模型」chips 一键回载；系统分析支持符号参数（如 (s+z)/(s+p)，自动生成参数框与扫掠列表，画一族曲线对比）；框图可「↗ 系统分析」、系统分析可「↗ 框图 / ↗ 求解」一键交接。
  • 系统分析：波特图/奈奎斯特图/根轨迹（适用于任意开环 L(s)：× 极点起点 · ○ 零点终点 · 虚线渐近线 · ◇ 实轴分离/汇合点 · 金点虚轴穿越 K*；K 滑杆拖动即查看该增益下的闭环极点与稳定性）；PM/GM 裕度；劳斯判据面板；特征方程分析（输入 D(s)=0 自动求根、判稳、给出 ζ/ωₙ 与自由响应曲线）。
  • PID 整定：闭环仿真，调 Kp/Ki/Kd 看响应指标与闭环极点。
  • 系统框图：教材符号体系——方框（传函）、求和点 Σ（圈上标 ±，点击即切换正/负反馈）、分支点。从端口拖出连线，拖到空白处松手可直接新建元件；无限画布（滚轮或双指缩放、拖空白平移、空格拖动）、框选与对齐辅助线、撤销/重做、双击就地编辑、右键（触屏长按）菜单、输入/输出端子 R(s)/Y(s)。自动合成 T(s)、闭环极点与稳定性、单位阶跃响应，并用「分享」生成可还原的链接。手机端单列堆叠、触控优先。
  • 交互求解：表达式自动识别（时域/传函）、实时识别徽标、符号键盘、历史记录、分享链接、手绘画圈、语音输入；符号变换含 f(t)→F(s) / F(s)→f(t) / f(t)→F(jω) / F(s)→X(z)（冲激不变法，采样周期 T 可调） / x(n)→X(z) / X(z)→x(n)。方程求解页签：输入微分方程（如 y''+3y'+2y=u(t)，支持 y2/y[[2]] 写法）或差分方程（y[n+2]−1.5y[n+1]+0.5y[n]=u[n]）与初值，自动给出全解 = 零输入 + 零状态的解析式、响应曲线与数值互证；「数据序列」模式粘贴一列数即可看序列与频谱。
  • 公式推导：性质表（傅立叶/拉普拉斯/Z）与变换对（含 ROC）、逐步推导（含 Z{aⁿu[n]}）、输入函数→变换推导（输入 f(t) 自动逐项推导 + 数值验证）；左栏 A+/A− 可放大公式。
