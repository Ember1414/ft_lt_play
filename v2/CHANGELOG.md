## [2.16.0] — 2026-10-16 · 复极点谐振器（Z 域阻尼振荡项 · M21）

> 承接 M20 §五遗留：「z 序列语法不支持 a^n·cos(w n)·u[n] 这类乘积组合 → 无法演示真正的复极点谐振器」。
> 本轮扩展内核（`core/transforms.ts` 解析 + `core/odesolve.ts` 逐项有理式），并补一组**闭式真值钉**。

### 新增
- **序列语法支持阻尼振荡项**：`r^n*cos(w*n)*u[n]`、`r^n*sin(w*n)*u[n]`（三种写法均可：带 `*u[n]` / `u[n]` / 省略），
  可与几何级数、斜坡、冲激等线性组合；X(z) 闭式 = `z(z−r cos w)/(z²−2r cos w z+r²)`（余弦）与
  `r z sin w/(z²−2r cos w z+r²)`（正弦），ROC 取 |r|。
- **复极点对**：`polyRoots` 与 Jury 判据按既有链路自动工作（极点 r·e^{±jw}、`ρmax=r`）。
- **𝒵⁻¹ 闭式**：`invZ` 的复极点分组分支（`2r^{n−1}[P cos(θ(n−1))+Q sin(θ(n−1))]`）首次被真正用到，
  「公式推导 · 离散」可给出谐振器的解析反变换并与直接序列逐点核对。
- 新增 **8 项内核断言**（`npm run audit` 第 10 组）：三种写法等价解析、表达式内混合项、闭式 X(z) 与 400 项截断求和一致、
  极点模与辐角精确等于 r 与 ±w、频响在 w 处 ≥3× 于 0 与 π/2、r=1 退化为非阻尼 cos（与 `zn` 分支逐系数一致）、
  r=0 退化为 δ(n)、ROC=|r|（0.9 而非 1）。

### 界面
- `z` 工具：预设新增「**谐振器**」（`0.9^n*cos(pi/4*n)*u[n]`，原「谐振（临界）」改名「临界谐振」）；语法提示与无法解析说明同步补该写法。
- 首页快速开始模板「极点逼近单位圆」升级为「**数字谐振器**」（复极点对 0.9e^{±jπ/4} · 频响峰值）。
- 「公式推导 · 离散」的语法提示同步。

### 质量
- `npm run check` 零错误；`npm run parity` **77/77 + 37/37**（v1 语法不含新项，对拍网不受影响）；
  `npm run audit` **10/10 组**（新增 1 组 / 8 项闭式真值）；`npm run uidata` **90/90**；`npm run build` 通过。
- 浏览器实测（`z` + `derive`）：谐振器 → 极点 2 / 零点 2、ρmax 0.900、Jury 4 条判据全过、频响在 ω≈0.785 出峰；
  离散推导给出 `X(z)=(z²−0.636z)/(z²−1.273z+0.81)`、𝒵⁻¹ `2·0.9^{n−1}[0.318cos(0.785(n−1))+0.318sin(0.785(n−1))]+δ(n)`，
  前 10 拍闭式与直接序列**逐点一致**（1, 0.636396, 0, −0.515481, −0.6561, …）。

## [2.15.1] — 2026-10-16 · 拖动条回归 + 缩放时纵轴自适应 + 框图框选/改接/捏合（M20 追加）

> 用户复核 2.15.0 的两条反馈：「改变参数大小的拖动条不要取消呀，而且缩放后曲线就只有一截呀」。
> 前者是 2.15.0 **误删**（用户要的是「不要 ⇔ 拖拽手柄、要 −/+ 按钮」，不是「不要滑杆」）；后者是纵轴不跟随。

### 修正
- **恢复参数拖动条**：`SliderField` 的 `withSlider` 默认回到 **true** —— 形态 = `标签 · − [数值框] 单位 +` + 拖动条，
  粗调用拖动条、微调用 −/+ 或键入；⇔ 拖拽手柄仍保持关闭（`grip` 默认关）。
- **坐标图：横轴缩放时纵轴自动贴合可视数据**（修正「缩放后曲线只有一截」）：放大后纵轴按当前 x 窗口内的
  数据范围取 ±8% 余量重算，曲线重新填满绘图区；缩回全宽（≥92% 基准跨度）自动恢复工具给定纵轴；
  Shift 滚轮缩放纵轴或竖向拖动后视为「用户手动定过纵轴」，不再自动贴合；双击复位清空该状态。
  纯横向平移（竖向位移 ≤4px）结束后同样贴合一次，避免平移后曲线又被压扁。

### 新增（框图交互，M20 未竟项）
- **框选**：`Shift + 拖空白`拉出选择框（可视矩形 + 状态行回显「框选中 N 个元件」），与 Shift 点选叠加。
- **连线改接**：拖动线中点徽标可把该连线的终点改接到别的元件（拖动中显示预览线 + 目标高亮，
  自环/重复/落空分别给出提示）；**原地单击仍是切换正负号**。
- **触摸双指捏合缩放**：两指按下进入捏合（取消其它手势），以两指中点为中心缩放（0.35×–3×）。

### 质量
- `npm run check` 零错误；`npm run parity` **77/77 + 37/37**；`npm run audit` **9/9**；`npm run uidata` **90/90**；
  `npm run perf` 主线程合计 **15.4 ms**；`build` 通过。
- 浏览器实测：`sys` 波特图/`ft` 谐波/`comm` 时域深度缩放后曲线纵向占图 **78% / 100% / 74%**（修正前 ≈10–20% 的一窄条）；
  19 视图 0 console error。

### 公式推导（④ ）
- **核心修复**：`itemLapTex` 的系数为 1 时分式分子为空（`\dfrac{}{s+2}`）→ 新增 `numTexOf`（分子部件相乘，
  常量 1 有其它因子时省略、但**不允许为空**）；`texp` 分支顺带修掉分子前导 `\cdot`。v1 内核 `lib/transforms.js` 同步修复，
  对拍（77/77 + 37/37）与 v1 单测保持全绿。
- **新增离散推导**：「自定义推导」加类型切换 **连续 ℒ / 离散 𝒵**——离散侧展示 ① 单边 Z 变换定义 ② 逐项变换对 →
  有理式合并（`combineFracs`）③ 极点/稳定性（ρmax、无极点=有限长序列、临界/不稳定）④ **𝒵⁻¹ 闭式**（`invZ` 部分分式+留数）
  ⑤ 数值核对表（闭式 vs 序列直接求值，前 12 拍）。
- **新增 s↔z 映射表**（性质表第 6 张）：冲激响应不变 / ZOH / 双线性(Tustin) / 后向差分的 **正反向公式 + 特性**
  （含预畸变 ω_a=(2/T)tan(ωT/2)）。
- TeX 导出按模式给出对应行（离散导出 x[n]、X(z)、ROC、𝒵⁻¹）。

### 顶栏（⑤ ）

### 系统框图（⑥ ）
- **端口被连线的命中带吞掉**（真缺陷）：端口外新增透明热区 `.blk-port-hit` 且位于连线上层 —— 此前从端口拖线会被
  `.blk-edge-hit`（14 单位命中带）拦截，表现为「点端口没反应/连线选不中」。

- 连线落点反馈：拖线途中目标元件高亮（`is-target`），松手给出「已新增连线 x → y / 已存在该连线 / 不能连接到自身 / 未落在元件上」。

  连续段失败原因不再被隐藏；纯增益闭环给出「无动态」说明而不是「暂无闭环解」；分支点也可删（去掉特例）。

### PID（⑦ ）
- **超调 Mp 对负设定值算错**：原 `peak=max(y)`，r<0 时峰值取到 y(0)=0 ⇒ 恒报 100%；改为按 r 符号取同向极值。
- **ts 顶窗静默**：窗口内未进入 ±2% 带时不再伪造「恰好 = tmax」，显示 `> tmax` 并标 warn；指标窗口自 `tr` 起算。
- **「微分先行」开关原本是空操作**（r 恒为常数 ⇒ Δe ≡ −Δy）：新增 **tr · 参考阶跃时刻**（0…tmax/2），tr>0 时
  误差微分与微分先行不再等价（微分踢可见）——实测 tr=1 s 时切换开关 ISE 0.568↔0.806、IAE 1.180↔1.708。
- **反算抗饱和 Tt 暴露为参数**（0.05–5 s，默认 1，含「≈Ti 或 √(Ti·Td)」提示），不再硬编码不可见。
- **数字 PID 实际控制周期**显式回显（`round(Ts/dt)·dt`，dt = tmax/1500；Ts 小于步长时提示已被量化）。
- ZN 的 Ku/Tu/ωpc 与一键换算经独立验算无误（默认对象 1/(s(s+1)(s+2)) → Ku=6.000、Tu=4.443 s、ωpc=1.414 rad/s）。
