# 系统框图 · 采样与离散分析（Z 域）设计说明

- 日期：2026-09-18
- 范围：`assets/js/lib/blocksolve.js`（新增纯函数）、`assets/js/modules/blockdiag.js`（新增符号 / 采样周期 / z 域页签）、`assets/js/lib/util.js`（`polyTex` 加变量参数）、`assets/css/style.css`、`index.html` 版本号；新增 `tests/blk-z.test.mjs`
- 目标：在现有系统框图上加入**采样开关**、**零阶保持器（ZOH）**、**全局采样周期 T**，并支持在 z 域给出**脉冲传递函数 T(z)**（解析式 + z 平面零极点 + 采样点响应），对齐教材的采样系统分析
- 前置文档：`2026-09-18-blockdiag-redesign-design.md`（符号体系 / 渲染分层 / 交互 / 移动端约定，本文沿用不重复）
- 非目标：
  1. 不做离散化**设计**方法（Tustin / 前向差分 / 零极点匹配 / 预畸变），只做"给定 s 域元件后的 z 域分析"
  2. 不做多速率采样、不做双线性变换后的 w 域频域设计
  3. 不引入任何第三方库（本站零依赖约定）
  4. 不重构 `explore.js` 中既有的数值法 s→z（其结果仅作为测试里的独立参照思路，见 §12 注）

## 1. 现状与缺口

| 类别 | 现状 | 缺口 |
| --- | --- | --- |
| 元件 | 方框 / 求和点 / 分支点 | 无采样开关、无零阶保持器，无法表达采样系统 |
| 求解 | `solveTransfer` 只处理 s 域有理块，返回 `T(s)` | 采样开关与 ZOH **没有有理传函**（ZOH 含 `e^{−sT}`），直接进现有求解会失败 |
| 时间 | 无采样周期概念 | 没有 `T` 就无法计算 `e^{pT}`，Z 域无从谈起 |
| 结果 | 合成传函 / 闭环极点（虚轴判稳）/ 阶跃响应 | 缺脉冲传函、z 平面（单位圆判稳）、离散序列响应 |

关键约束（决定了本文的算法形态）：**一般采样系统（采样器位置任意、连续与离散混在环内）不存在纯 z 的有理闭环传函**。只有满足 §5 的可归约条件时 `T(z)` 才是严格有理函数；其余情形必须明确报"不支持"并解释原因，而不是硬凑一个结果。

## 2. 架构与新增 API

求解层继续与 DOM 解耦，全部新增逻辑放在 `window.BLKSOLVE`（纯函数，Node 可测）：

| 导出 | 作用 |
| --- | --- |
| `parseBlockTF(str, dom = 's')` | 扩展：`dom === 'z'` 时按变量 `z` 解析（`FX_LIB.parseTF(s, 'z')`）。其余判定（分母首项非 0 / 非真分式 / 约分归一）不变 |
| `sToZ(n, d, T)` | **`Z[G(s)]`**，解析式精确系数，返回 `{ ok, n, d, note }` |
| `zohDiscretize(n, d, T)` | **`(1−z⁻¹)·Z[G(s)/s]`**，返回 `{ ok, n, d, note }` |
| `analyzeSampled(nodes, edges, T)` | 域传播 + 采样器归约 + 连续片段划分，返回 `{ ok, mode, segs, g, note }`；`g` 为**归约后的纯 z 图**（不改动编辑器状态） |
| `solveSampled(nodes, edges, T)` | 顶层入口：`{ ok, mode, z:{n,d}, segs:[{in,out,Ts,Tz,hasZoh}], note }` |
| `deriveZReadout(frac)` | 由 `T(z)` 派生阶次 / 极点 / 稳定性（**单位圆判据**）与零点 |

`mode` 三态（决定 UI 走哪条路径）：

| `mode` | 含义 |
| --- | --- |
| `'s'` | 无 `sample` / `zoh` / `dom='z'` 块 → 完全走现有 s 域路径，**行为与现状逐位一致** |
| `'z'` | 有采样元件或 z 块，但归约后没有虚拟块（纯 z 图）→ 全离散回路 |
| `'sampled'` | 存在连续片段（生成了虚拟 z 块）→ 标准采样回路 |

`blockdiag.js` 职责：新增符号、`T` 输入、检查器的"已在 z 域"开关、z 域结果页签与两块画布。

## 3. 数据模型

```js
node = {
  id,
  kind: 'box' | 'sum' | 'branch' | 'sample' | 'zoh',   // 新增两种
  dom:  's' | 'z',          // 仅 box 有意义，默认 's'；'z' = 表达式已在 z 域
  name, str,
  f,                        // box：{ n, d }；sum/branch 恒为 { n:[1], d:[1] }；sample/zoh 恒为 null
  err, errNote,             // 仅 box
  x, y, src, out
}
```

模块级状态新增 `T`（采样周期，单位 s；默认 `0.1`；约束 `1e-3 ≤ T ≤ 1e3`）。

规则：

1. `sample` / `zoh` **没有 `f`，也不算 `err`**（它们不是"表达式无效"）。现有求解前的过滤 `!n.err && n.f` 天然把它们排除在能控规范型实现之外 —— 因此**必须先做 §5 的离散化归约把它们消掉**，才能进 `solveTransfer`。
2. `zoh` 的输入必须是采样信号（见 §6 U3）；`sample` 的输入可以任意。
3. `dom === 'z'` 的 box 参与 z 图求解；`dom === 's'` 的 box 只能出现在连续片段内。
4. 归约算法只在**派生副本**上操作（新的节点/边数组），不修改编辑器状态，因此可被单测直接驱动。

## 4. 数学内核（`sToZ` / `zohDiscretize`）

### 4.1 基本公式

```
Z[G(s)] = Σ_p Σ_{k=1..m_p} A_{p,k} · Z_k(p)
Z_k(p)   = 1/(k−1)! · ∂_p^{k−1} [ z / (z − u) ],   u = e^{pT}
```

部分分式直接复用 [partialFracGroups](file:///e:/Projects/ft_lt_play/assets/js/lib/transforms.js#L296-L342) 的成果：`groups[{ p:{re,im}, m, A[] , pair }]` + `direct`（它内部已用 `DSP.polyRoots` 分组重根、标注共轭对，正是本式需要的形态）。

- **单实极点（m=1）**：`A₁ · z/(z − u)`。
- **共轭对（`pair`，m=1）**：两个复极点合并为实系数二次式
  - 分母：`z² − 2e^{σT}cos(ωT)·z + e^{2σT}`（`p = σ ± jω`）
  - 分子：`z · [ 2Re(A) · z − 2Re(A·e^{p̄T}) ]`（利用 `conj(A e^{p̄T}) = Ā e^{pT}`）
  - 保证输出分母全程**实系数**，KaTeX 显示干净。
- **重实极点（m>1）**：用**精确递推**，不做数值差分：
  ```
  P_0 = z,  u = e^{pT}
  P_{j+1} = (z − u)·∂_p P_j + (j+1)·T·u·P_j
  第 k 项 = A_k · P_{k−1}(z) / (z − u)^k
  ```
  实现上 `P_j` 的 `z^i` 系数是 `u` 的单项式（记录幂次整数），故 `∂_p(u^s) = s·T·u^s` 精确。已用 Z 变换表验算：
  `k=2 → T·z·u/(z−u)²`；`k=3 → T²·z(z+u)/(2(z−u)³)`，与教材一致。
- **直通项**：`pf.direct ≠ 0`（分子阶次 = 分母阶次）时，采样后对应 `b₀·δ[n]`，处理方式与既有 [invZ](file:///e:/Projects/ft_lt_play/assets/js/lib/transforms.js#L496-L511) 完全一致（把 `b₀` 记为常数分子项）。
- **合并**：各组补因子到公共分母 `(z − u)^{m}` 后累加实系数多项式；再 `freduce` 约分。

### 4.2 ZOH

```
ZOH ∘ G(s)  →  (1 − z⁻¹)·Z[G(s)/s]     // G(s)/s 即分母前插 0（乘 s）
```

例（也是 §11 的对照用例）：`G(s)=1/(s+1)`，
`Z[1/(s(s+1))] = z(1−e^{−T})/((z−1)(z−e^{−T}))`，乘 `(1−z⁻¹)=(z−1)/z` 得
**`G_zoh(z) = (1−e^{−T})/(z − e^{−T})`**（DC 增益 `z=1` 处为 1，与被控对象 DC 增益一致，可作自检）。

### 4.3 z 域元件

`dom === 'z'` 的块直接使用，**不做任何变换**；全离散回路把 z 块交给现有 `solveTransfer` —— 该内核的数学（能控规范型 / 代数回路 / 零极点对消）与变量名无关，**s 域与 z 域同构**，只是判稳从虚轴换成单位圆。

### 4.4 数值边界

| 情况 | 处理 |
| --- | --- |
| `T ≤ 0` 或非有限 | `{ ok:false, note:'采样周期 T 必须为正数' }` |
| `u = e^{pT}` 溢出（`p.re·T` 过大） | 截断并给 `note`，不抛异常 |
| 两个不同 s 极点因**混叠**映射到同一 `z`（相差 `j2π/T`） | 合并分母因子（按 `u` 值容差 `1e-9` 归并），避免出现重复因式 |
| 无有限极点（如纯多项式 G(s)） | `{ ok:false, note:'G(s) 无有限极点，Z[G] 不是有理函数' }` |

## 5. 拓扑归约算法（`analyzeSampled`）

### 5.1 域传播

| 节点 | 输出域 |
| --- | --- |
| `sample` | **z**（是连续片段的"终点"） |
| `zoh` | **连续**（是连续片段的"起点"，其 z 等效头因子为 `(1−z⁻¹)`）；输入必须已是 z，否则 U3 |
| `box, dom='z'` | **z**（输入必须已全为 z，否则 U4） |
| `box, dom='s'` | **连续**（连续时间元件，输出恒为连续波形；即使被离散信号驱动，输出仍是连续信号，其"被采样后的等效"由片段离散化给出） |
| `sum` / `branch` | 任一输入为连续 → 连续；否则 z |

> 关键点：`box, dom='s'` **不因输入是 z 就变成 z 域**。它必须与"它的输出被采样"这一事实一起，才能合成为 `Z[G(s)]`；这正是 §5.3 片段离散化的职责。早期草稿里"全部输入为 z → 输出 z"的写法与片段划分冲突，已按此修正。

### 5.2 采样器下沉（利用 Z 的线性性与 Σ 的无记忆性）

`Z` 是线性的、`sum`/`branch` 是无记忆增益 1，因此 `Z[a + b] = Z[a] + Z[b]`，**采样器可以"沉"过求和点**：

```
若采样器 S 的输入来自连续的无记忆节点 m（sum/branch）：
  对 m 的每一条入边 (u→m) 插入一个新的采样器 S_u（u → S_u → m），删除 S；
  迭代直到没有采样器直接读取连续的无记忆节点（m 随之变为 z 域）
若某条入边的源已是 z 域信号（源是采样器输出 / z 域块输出）→ 该支路冗余，
  直接接上、不插入采样器（U5 的"视为直连"）
若某条入边的源是外部参考 R（`src` 标记）→ 不插入实体采样器，
  而是把参考直接视为离散序列 R(z) 注入同一个 m（教材惯例）
```

这条规则覆盖了最经典的教科书结构（误差点采样）：

```
R(s) ─→ Σ ─→ S ─→ D(z) ─→ ZOH ─→ G(s) ─→ Y(s)
        ↑                                    │
        └────────────── S ←──────────────────┘
```

下沉后等价于：`R → S → Σ(z)`（R 支路被采样）、`Y → S₂ → Σ(z, 取负)`、`Σ → D(z) → ZOH → G(s) → Y`，
即 `E(z) = R(z) − Y(z)`、`Y(z) = D(z)G_zoh(z)E(z)` ⇒ `T(z) = D(z)G_zoh(z)/(1 + D(z)G_zoh(z))`。
**参考输入按采样序列 `R(z)` 处理**（教材惯例，`R(s)=1/s` 时取 `R(z)=z/(z−1)`）。

### 5.3 连续片段与虚拟 z 块

1. **片段** = 连续动态元件（`box, dom='s'`）与未被下沉的连续无记忆节点的连通分量，其边界必为 `sample` / `zoh`。
2. **入口** = 被某个 `sample` 或 `zoh` 输出直接喂入的元件；**出口** = 其值被某个 `sample` 读取、或被标记为输出的元件。
3. 对每个（入口 a，出口 b）在片段子图上跑一次现有 `solveTransfer(片段, src=a, out={b})` 得 `T_{a→b}(s)`；**片段内部的纯连续局部反馈自动被解掉**（复用能控规范型 + 代数回路求解）。
4. 离散化：
   - 入口由 `sample` 喂入 → `T_z = sToZ(T_{a→b})`
   - 入口由 `zoh` 喂入 → `T_z = zohDiscretize(T_{a→b})`，且该 `zoh` 节点被吸收（其离散输入源直接连到虚拟块）
   - 出口无采样器读取（直接是输出端子） → `T_z = sToZ(T_{a→b})`，结果标注为**采样时刻输出 `Y*(z)`**
5. 归约后的纯 z 图：`sample` 退化为传函 1 的节点（其离散输出即其输入的 z 值）、被吸收的 `zoh` 消失、无记忆节点退化为传函 1，连续元件被虚拟 z 块替换 → 交给 `solveTransfer`（变量 z）。

**v1 支持范围（收敛版）**：每个连续片段 **恰好一个入口**、出口可多个（各出口各生成一个虚拟块）。多入口 → 不支持（见 §6 U2）。

### 5.4 归约范例（本文档的"可执行规格"）

`R → Σ(src) → S₁ → D(z) → ZOH → G(s) → Y(out) → S₂ → Σ(−1)`，`D(z)=(z−0.5)/(z−1)`，`G(s)=1/(s+1)`：

- 域传播：`Σ` 输入含 R（连续）与 `S₂` 输出（z）→ 混合，但采样器下沉后 `Σ` 变为 z。
- 片段：`{G}`（一个连续动态元件），入口 = `G`（由 ZOH 喂入），出口 = `G`（`S₂` 读取，且标记 `out`）。
- `T_{a→b}(s) = 1/(s+1)`，`G_zoh(z) = (1−e^{−T})/(z−e^{−T})`。
- 纯 z 图：`E = R − Y`，`Y = D(z)·G_zoh(z)·E` ⇒ `T(z) = D G/(1 + DG)`，展开后为 z 的有理函数（与手算对照，见 §11）。

## 6. 不支持条件与提示文案

| 代号 | 触发条件 | 提示文案（结果区原样显示 `note`） |
| --- | --- | --- |
| U1 | 连续动态元件的输出既不被任何采样器读取，也不是输出端子 | 存在未被采样的连续元件，信号未经过采样就参与回路 —— 此类混合系统的闭环脉冲传函不是 z 的有理函数 |
| U2 | 同一连续片段有 2 个以上入口（多个采样点驱动同一连续段） | 同一连续片段被多个采样点驱动（多速率 / 多输入），本版本不支持 |
| U3 | `zoh` 的输入不是采样信号（上游既非 `sample` 也非 z 域块） | 零阶保持器的输入必须是采样信号，请在其前面加采样开关 |
| U4 | 连续元件与 z 域元件**直接相连**（中间既无 `sample` 也无 `zoh`，任一方向） | z 域元件与连续元件之间必须插入采样开关或零阶保持器 |
| U5 | 采样器输入已是 z 域信号 / 采样器输出直连采样器 | 允许（视为直连），仅给一行提示 |
| U6 | 片段求解失败（沿用现有 `solveTransfer` 的 note） | 原样透传（如"存在无延迟代数环"） |
| U7 | 无输入源 / 无输出端子 | 沿用现有文案 |

**为什么 U1 不能硬凑**：连续元件未被采样时，其输出含连续时间信息，闭环响应在采样点之间也有效；对其强行取 `Z[·]` 会得到"看起来像"但**与真实采样值不符**的结果。宁可明确报错并解释，也不给出误导性的 `T(z)`。

### 7.4 结果页签

| 模式 | 页签 |

1. KaTeX `T(z)=\dfrac{N(z)}{D(z)}`（变量 z）+ 指标行：阶次 / 闭环极点 / 稳定性（**`|z|<1` 判据**：`稳定（单位圆内）` / `不稳定（存在单位圆外极点）` / `临界（存在单位圆上极点）`）
2. **z 平面零极点**画布：复用现有 `drawPoles` 骨架，把"虚轴 + 左右半平面"换成"**单位圆** + 圆内/圆外"（着色沿用 `--cv-stable-bg` / `--cv-unstable-bg`，单位圆用 `--cv-axis-hi`），× 表示极点、○ 表示零点
3. **采样点响应**画布：`R(z)=z/(z−1)` 单位阶跃，`Y(z)=T(z)·z/(z−1)` 约分后用 `TR.invZ(...).evalN(n)` 逐点求值，`n = 0..N`（`N` 取 30–60，按极点的 `|z|` 与收敛速度定）；以杆状（stem）图绘制，存在单位圆外极点时曲线转 `--danger`
4. 若存在多个连续片段 → 折叠区展示中间结果表：`T_{a→b}(s)`、是否含 ZOH 头因子、离散化后的 `T(z)`

`连续片段 T(s)` 页签：逐片段列出 `T_{a→b}(s)` 与 `T_z`，用于教学对照（把"先把每一段离散化、再在 z 域求闭环"这件事显式化）。

采样模式下原 `合成传函 T(s)` / `闭环极点` / `阶跃响应` 三个页签**全部让位**给上述两个页签（s 域闭环传函对采样系统本身没有意义，其 z 域内容已并入 `脉冲传函 T(z)`），因此不会出现两套语义混淆的画布；无采样时保持现状。

## 9. 错误处理与数值边界

| 情况 | 处理 |
| --- | --- |
| `T` 非法 | 输入框描边转红 + 内联提示，沿用上次有效值，不重解 |
| `sample`/`zoh` 被误当作 box 参与解析 | 不会发生：`f` 恒为 `null`，且归约在求解前完成；契约测试断言二者不产生 `err` |
| `sToZ` 失败（无有限极点 / 部分分式失败） | 结果区显示 `note`，不显示空图 |
| z 域结果出现 NaN/Inf | 指标显示 `—` + 一行说明（沿用现有约定） |
| 无采样元件时误点 z 页签 | 不可能：页签集合按模式生成 |
