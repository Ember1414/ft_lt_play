# M10 验收单 · 备份含自建剧场剧本（数据完整性）

> 依据：M9 验收单 §五 第 1 项——「自建剧本**不随实验备份导出**（设置 · 备份与恢复只覆盖实验）」。
> 本里程碑把「自建剧场剧本」并入备份/恢复与「恢复出厂设置」，让 M9 新增的数据存储也被完整管理。
> 交付 = 可运行版本 + 本验收单。版本 **2.5.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 打包（导出） | 备份包新增 `theaterCount` + `theaterScripts`（自建剧本数组；**内置剧本属代码内置，不入包**）；`设置 · 备份与恢复` 主按钮改为「导出全部数据（JSON）」，toast 显示「N 个实验 + M 部自建剧本」 |
| 解析（导入） | 新增 `report/backup.ts` 纯函数层：`buildBackup()` / `readBackup()`；`readBackup` 定位 `experiments` 与 `theaterScripts`（**不校验项内数据**，交给调用方） |
| 逐项校验 | 实验仍走 `core.importJSON`（迁移 + 规范化）；剧本走 `state/theater.saveUserScript`（`sanitizeScript` 规范化 + 按 `u-` id 覆盖） |
| 计数与提示 | 导入 toast 分别报实验与剧本的成功 / 失败，剧本**覆盖**数单独标出（如「自建剧本 成功 2（覆盖 2）」） |
| 兼容性 | 旧版备份无 `theaterScripts` → 只恢复实验（toast 不出现剧本段）；历史「单实验文件」（根节点即实验）仍按 `[root]` 处理 |
| 恢复出厂设置 | 确认文案补「自建剧场剧本」；执行时调用新增的 `clearUserScripts()`（此前只清实验与偏好，剧本会被静默保留） |
| 存储卡片 | 指标行新增「自建剧场剧本」（与「实验数」并列；按存储键明细里本就有 `flt2:theater:scripts`） |

## 二、功能验收清单

- [x] 导出包结构：`kind:'fltp-backup'` + `count` / `experiments` / `theaterCount` / `theaterScripts` / `exportedAt`
- [x] 往返一致：`buildBackup → JSON → readBackup` 后剧本数组逐字节一致
- [x] 旧备份（无剧本字段）→ `theaterScripts === null`，只恢复实验
- [x] 历史单实验文件 → `experiments = [root]`（行为与 M2 一致）
- [x] 非法 JSON → 具体原因「不是合法 JSON 文件」（不静默）
- [x] 导入剧本按 `u-` id **幂等覆盖**：重复导入同一包 → 覆盖计数增加、总数量不变（不产生副本）
- [x] 包内非法剧本（`null` / 空名称）被 `saveUserScript` 拒绝并计入失败，**不影响**同包内合法项
- [x] **浏览器实测**（零 console error）：新建自建剧本「备份冒烟」→ 设置中心「自建剧场剧本」= **1** →
      点「导出全部数据（JSON）」→ toast「**已导出备份（0 个实验 + 1 部自建剧本）**」→
      点「恢复出厂设置」（确认框已含「自建剧场剧本」）→ 存储卡片两项均归 **0** → 剧场页「共 5 部剧本（内置 5 部 / 自建 0 部）」且列表无「备份冒烟」

## 五、说明与遗留

1. 备份包**不含内置剧本**（属代码内置，随版本走）；也不含主题 / 动效偏好与学习路径进度（后者仍由各自入口管理，见设置中心「存储」卡片）。
2. 「22 项备份数据通路断言」原为临时脚本，**已并入 CI → `scripts/uidata.mjs`**（`npm run uidata` 的第 ② 组，
   现有 22 条；见《M13 验收单》）。该脚本与 `parity.mjs` / `audit.mjs` 同一手法（esbuild 打包 +
   `localStorage` 桩），定位为**内核之外**的 UI 数据层门。
3. 备份包**不加密、不压缩**：导出为本地文件（体积随实验数与剧本数线性增长）；分享码长度上限不适用于备份文件。
4. 剧本单文件通道（`TS1.…` 分享码 / 剧本 `.json`）仍保留于「演示剧场」页，与整包备份互补。
5. 其余已知边界见《M4 §五》第 1/3 项与《M5/M8 验收单》§五；其中「`nyquistFull.onCritical` 临界点采样」
   已由 **M11 完成**（邻域加密 + 圈数精度修正，见《M11 验收单》）。
