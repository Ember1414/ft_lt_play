# M11 验收单 · 奈奎斯特临界点精确判定（临界邻域加密 + 圈数精度修正）

> 依据：M4 验收单 §五 第 5 项——「`nyquistFull.onCritical` 的采样限制：临界增益下曲线严格**相切** (−1,0)
> 时未必被离散采样捕获 → 判为 N=0、Z=0、stable=true（实为临界）……如需精确临界判定，应在 (−1,0) 邻域自适应加密采样」。
> 本题按该建议实现，并在过程中发现同一根因导致的**更严重缺陷**（圈数漏算，见 §四），一并修正。
> 交付 = 可运行版本 + 本验收单。版本 **2.6.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 临界邻域自适应加密 | `core/dsp.ts` 的 `nyquistFull`：在粗采样最接近 (−1,0) 的**虚轴线段** `[ω_{k−1}, ω_{k+1}]` 上逐级加密——每轮把搜索半径缩 16 倍、均匀取 33 点，共 7 轮（对多极小 / 非单峰同样稳健）；用**加密子路径替换该段的辐角贡献**，并把 `minDist` 收敛到真实极小值 |
| 轴段采样密度 | 虚轴直线段采样由 v1 的 **500 点/段**提升为 **5000 点/段**（`NYQ_AXIS_SEG`）：折线跟踪误差 ~ O(步长²) 下降约 100 倍，「刚越过临界增益」时的整圈包围不再被折线「抄近道」漏算 |
| 判定语义不变 | 返回字段与阈值表达式一字不改：`onCritical = minDist < TOL_REL·scale`、`stable = Z===0 && minDist > TOL_REL·scale`；`P/N/Z` 仍按 `Z = N + P`、`N = round(−ΣΔarg / 2π)` |
| indent / 大半圆 | 不变（48 点 / 80 点），因此 `den=[1,-1]` 这类「刀锋」用例（轨迹严格过 (−1,0)）行为与 v1 保持一致 |

## 二、功能验收清单

- [x] **严格相切**：`G=8/(s+1)³`（闭环极点恰在 ±j√3）→ `onCritical=true`、`stable=false`（M11 前为 `false/true`）
- [x] **临界家族二**：`G=6/(s(s+1)(s+2))`（闭环极点 ±j√2，含原点极点需 indent 绕行）→ `onCritical=true`、`Z=0`
- [x] **不漏圈（M11 前的主要缺陷）**：`G=9/(s+1)³` 由 `Z=0`（误报稳定）修正为 `Z=2`（真值：Routh 第 3 行变号 → 2 个右半平面根）
- [x] **同族第二例**：`G=6.1/(s(s+1)(s+2))` 由 `Z=0` 修正为 `Z=2`
- [x] **不误报**：`K=7`（族一）、`K=5`（族二）等临界前档位仍 `Z=0`、`stable=true`、`onCritical=false`
- [x] **远区不变**：16 组对拍用例（4 固定 + 12 随机）的 `P/N/Z/stable/onCritical` 与 v1 完全一致 → `npm run parity` 77/77 + 37/37
- [x] **浏览器实测**（零业务 console error）：`系统分析` 设 `L(s)=1/(s^3+3s^2+3s+1)`（≡1/(s+1)³）后，
      K=1 → 「闭环 稳定（Z=0）」；**K=8 → 「闭环 临界（Z=0）」**；**K=9 → 「闭环 不稳定（Z=2）」**；K=7 → 「闭环 稳定（Z=0）」
- [x] 审计 #12 由 3 条扩为 8 条闭式断言（含上述临界前 / 临界 / 临界后三档，跨两个传函族）

## 四、缺陷记录

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | **临界标志漏判**（M4 §五 已记录）：严格相切时粗采样错过极小值 → 临界增益被判「稳定」 | 临界邻域自适应加密（本题主目标） |
| 2 | **圈数漏算（本题新发现，M4 未记录）**：折线在快速区段「抄近道」，穿越负实轴的落点被抬高到 −1 右侧 → 整圈包围被漏掉。真值 2 个右半平面根（Routh 判据）却报 `Z=0`、`stable=true` —— 影响面 **不是窄带**：族一 `K∈(8, ~10.7)`、族二 `K∈(6, ~6.6)`（约为临界增益的 1.0–1.35 倍），即开环增益刚越过临界增益的整个区间都误报「闭环稳定」 | 轴段采样 500 → 5000 点/段；实测该区间全部修正（见 §二/§三） |

## 五、说明与遗留

1. **残留窗口（≤0.9%）** → **M14 已闭合**：该窗口的根因并非「固定密度不够」，而是加密只覆盖了**单个**近临界段
   （该族在 ω=±√2 有两个对称穿越，只修一处只补回半圈）；现加密**全部互不相邻**的近临界段，
   并把 `K=8.01 / 6.01 / 6.02` 等「刚越过临界」档位写进审计 #12 的闭式断言（见《M14 验收单》§一/§三）。
   同时实测证明「相邻档结果一致」不能作为正确性判据（粗采样可能稳定地漏看局部几何）。
2. 加密只在**虚轴直线段**上进行；若临界邻域恰落在 indent 弧段（虚轴极点附近）或位于首/末采样点，则跳过加密（保持 v1 行为）。
3. `den=[1,-1]`（轨迹严格过 (−1,0)）属「刀锋」用例：`minDist=0` → 跳过加密，`N=0、Z=1、onCritical=true` 与 v1 完全一致（回归网要求）。该例闭环实为**临界**（闭环极点在原点），标志正确、Z 计数为约定相关项。
4. 采样密度提升只影响 `nyquistFull` 内部围线，**不触碰任何容差常量**（`core/tol.ts` 一字未改）；
   其余 12 个内核模块完全未改，对拍网 77/77 证实数值等价。
5. 其余已知边界见《M10 验收单》§五（备份包不加密、剧本单文件通道等）。
