# M21 验收单 · 复极点谐振器（Z 域阻尼振荡项）

> 依据：`v2/CHANGELOG.md` **2.16.0**（M21）。承接 M20 §五遗留——
> 「z 序列语法不支持 `a^n·cos(w n)·u[n]` 这类乘积组合 → 无法演示真正的复极点谐振器」。
> 交付 = 可运行版本 **2.16.0**（commit `b4003c1`，2026-10-16）+ 本验收单。

## 一、交付内容（对应 CHANGELOG 2.16.0）

| 类别 | 内容 | 验收证据 |
|---|---|---|
| 内核 · 序列语法 | `r^n*cos(w*n)*u[n]`、`r^n*sin(w*n)*u[n]`（带 `*u[n]` / `u[n]` / 省略三种写法均可），可与几何级数、斜坡、冲激线性组合；X(z) 闭式 = `z(z−r cos w)/(z²−2r cos w z+r²)`（余弦）与 `r z sin w/(z²−2r cos w z+r²)`（正弦），ROC 取 \|r\| | `core/transforms.ts` 解析 + `core/odesolve.ts` 逐项有理式；audit 第 10 组：三种写法等价解析、表达式内混合项 |
| 内核 · 复极点对 | `polyRoots` 与 Jury 判据按既有链路自动工作（极点 r·e^{±jw}、ρmax=r） | audit：极点模与辐角精确等于 r 与 ±w |
| 内核 · 𝒵⁻¹ 闭式 | `invZ` 复极点分组分支（`2r^{n−1}[P cos(θ(n−1))+Q sin(θ(n−1))]`）首次被真正用到 | audit：闭式 X(z) 与 400 项截断求和一致；r=1 退化为非阻尼 cos（与 `zn` 分支逐系数一致）；r=0 退化为 δ(n)；ROC=0.9 而非 1 |
| 审计钉 | 新增 **8 项内核断言**（`npm run audit` 第 10 组），含频响在 w 处 ≥3× 于 0 与 π/2 | `npm run audit` **10/10 组**（原 9 组 + 新 1 组 / 8 项） |
| 界面 · z 工具 | 预设新增「**谐振器**」（`0.9^n*cos(pi/4*n)*u[n]`）；原「谐振（临界）」改名「临界谐振」；语法提示与无法解析说明同步 | 浏览器实测：谐振器 → 极点 2 / 零点 2、ρmax 0.900、Jury 4 条判据全过、频响在 ω≈0.785 出峰 |
| 界面 · 首页 | 快速开始模板「极点逼近单位圆」升级为「**数字谐振器**」（复极点对 0.9e^{±jπ/4} · 频响峰值） | 首页模板卡可见并可一键创建（M22 批次 A 起由 e2e 冒烟覆盖首页模板创建路径） |
| 界面 · 公式推导 | 「公式推导 · 离散」语法提示同步阻尼振荡写法 | 浏览器实测：离散推导给出 `X(z)=(z²−0.636z)/(z²−1.273z+0.81)`、𝒵⁻¹ `2·0.9^{n−1}[0.318cos(0.785(n−1))+0.318sin(0.785(n−1))]+δ(n)`，前 10 拍闭式与直接序列逐点一致（1, 0.636396, 0, −0.515481, −0.6561, …） |
