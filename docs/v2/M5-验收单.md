## 四、缺陷记录

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | `chart/Chart.tsx` 的注册 id 若写成 `useRef(PRIMARY_ID++)` 会**每次渲染都自增**（参数表达式每帧求值） | 改为惰性初始化：`ref.current == null` 时才分配 id |
| 2 | 覆盖通道若发布**部分**参数会顶掉工具其余参数（工具的 `apply` 接收全量对象） | `apply()` 以「存储中的全量参数 + 本步部分覆盖」合成 `target` 再发布，保证全量语义 |
| 3 | 覆盖通道若对**枚举型**参数做插值会传入非法中间值（如 `terms=2.7`） | `interpKeys` 排除「整数↔整数」对，枚举参数保持跳变 |
