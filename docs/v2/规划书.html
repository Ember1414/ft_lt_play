1项目背景与目标

1.1 项目是什么 · 现状盘点

「信号与控制实验平台」是一个纯前端、本地优先（local-first）的信号与控制通用交互工具箱：面向一切与信号、变换、系统、控制打交道的人——不限定课堂或教学场景；以"实验（工作状态）"为单位组织操作——输入信号/传函/方程 → 仿真可视化 → 保存快照 → 分享导出。全部计算与存储在浏览器完成，无服务端、无数据上传，部署于 Cloudflare Pages（免费）。

维度现状（v1.1.3）
功能模块10 个：工作台 / 傅立叶级数 / 傅立叶变换 / 拉普拉斯 / Z 变换 / 系统分析 / PID 整定 / 系统框图 / 交互求解 / 公式推导
核心资产13 个自研库（数值内核、符号变换、框图求解、状态空间、数据模型、绘图与输入组件）；自研 FFT/求根/留数法/RK4/Jury/奈奎斯特/根轨迹等算法，全程无 eval
工程基线30 个零依赖测试脚本（约 830 断言）、CI 四步质量门、CSP 安全头、PWA 离线、版本化实验存储与分享码（PX1）
设计现状浅色默认 + 深色主题、设计令牌、SVG 图标、桌面侧栏 + 移动底栏；视觉量级停留在"精修过的演示工具"，未到专业产品水准

2.1 目标用户（不限定课堂）

产品面向一切与信号、变换、系统、控制打交道的人——以下是常见画像，而不是边界；任何人都不应被"教学假设"挡在门外。

工程师 / 研究者
随手可得的专业工具：传函分析、PID 整定、离散化验证、滤波器设计。核心诉求：快（键盘流）、准（数值可信）、可导出（CSV / 报告）。
教师 / 讲师 / 团队负责人
演示与分发：把一套"预置内容 + 题目"打包分享、回收可读成果（课堂、内训、评审皆可）。核心诉求：省时、可复用、零门槛分发。
学生 / 自学者 / 爱好者
需要"看得见"的直觉与可提交的成果。核心诉求：从哪开始（路径可选）、我懂了吗（自测）、怎么交（报告）。
跨领域技术人员
音频 DSP、嵌入式、通信、数据分析、科研绘图……按需取用单个工具，不必理解整个平台。核心诉求：直达、专业、可组合。

2.2 角色与权限层级

〔不适用说明〕本产品 local-first、无账号体系，因此不存在传统"注册/登录/权限层级"。v2 采用视角模型替代：

视角能做什么数据边界
所有者（本机用户）全部功能：创建/编辑/删除实验、导入导出、管理本地数据浏览器本地存储，仅本机可见
分享接收者打开链接后获得一份只读副本并可"另存为我的实验"后自由编辑不接触分享者的其他任何数据
内容包接收者（学员 / 协作者）打开内容包 = 获得预置实验与题目；完成后导出"提交包"同上；提交包由接收方手动回传（不经服务器）

如未来引入可选云同步（P1），届时再定义账号与权限模型；v2.0 不做（见 §3.3）。

6.6 架构形态与迁移策略

  • 形态：单体静态应用（模块化内核 + 组件化外壳 + Worker 计算层）；不是微服务，也无需 Serverless。
  • 迁移原则：内核"搬运 + ESM 封装"，不重写算法；外壳全部重写；每完成一批即以现有测试 + E2E 回归，里程碑门把关。
  • 并行策略：v2 在独立分支/目录开发；v1 线上持续可用；上线时切换并保留回滚点（D4 决定去留形态）。

8.8 交互原则（十条）

  1. 直接操纵优先：能拖的就不填表；参数就在图上。
  2. 即时反馈：交互 <100ms 有响应；长任务必有进度与取消。
  3. 永远可撤销：用户敢探索，是体验的上限。
  4. 渐进披露：默认折叠次要图表（延续 v1 的克制基因）。
  5. 一致优于个性：骨架、快捷键、文案模板全站统一。
  6. 键盘与鼠标同权：核心旅程全键盘可完成。
  7. 空态是引导、错误态是出路：每个空态都给出下一步按钮；错误必须给原因与替代路径。
  8. 不打断：无强制弹窗、无横幅骚扰；提示轻量且可关。
  9. 数据可视决定论：同一数据 → 同一张图（算法确定、无随机美化）。
  10. 尊重用户节奏：动画可关、状态不丢、刷新可恢复。
