# M12 验收单 · 对比页可调参数表补齐枚举 / 开关 / 表达式参数

> 依据：M8 验收单 §五 第 1 项——「可调项**仅限数值参数**；枚举 / 表达式类参数（如 `view`、`expr`）不在本表内，
> 仍沿用槽值。如需全部可调，可在对比页接入各工具的完整参数面板（工作量较大，按需评估）」。
> 本里程碑以**类型感知的参数表**（不侵入 13 个工具）兑现该缺口。交付 = 可运行版本 + 本验收单。版本 **2.7.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 可调键 | `pages/Compare.tsx`：可调键 = 两侧参数的**标量键并集**（`number` / `string` / `boolean`）；对象与数组（如自定义条目列表）不进表 |
| 控件分派 | 新增页内 `ParamCell`：数值 → `NumField`（步长/小数位按量级）、布尔 → `Switch`（点击切换）、字符串·枚举·表达式 → 文本输入（原生 `change`：失焦或回车提交） |
| 实时链路 | 沿用 M7/M8 既有的**分组覆盖通道**：编辑 → `publishLiveOverride('ab-a'/'ab-b', toolId, params)` → 两实例就地 `apply`（各自 `sanitize`）→ 对照曲线与两个实例画面实时刷新 |
| 不写回存储 | 编辑仍只作用于本页双跑实例（`setSuppressSave` 覆盖期），不写回实验存储 |
| 提交节奏 | 文本走原生 `change`（失焦 / 回车）而非逐键 `input`：避免每敲一个字符就触发两侧实例重算（动画型工具会明显受益） |
| 文案 | 表头改为「参数（可直接调 · 数值 / 开关 / 枚举·表达式 · A / B 双跑实时响应）」，并补一句控件与提交方式说明；空态文案改为「没有可调的标量项」；顺带修正快照叠加区那句已过时的「需工具支持以外部参数运行」 |

## 五、说明与遗留

1. **无效取值不提前拦截**：字符串 / 枚举参数按工具内取值填写，取值非法时工具自身回退默认（提示已在表下说明）。
   表格显示的是「你提交的值」，实际生效值由工具决定——若要两者一致，需要一条「实例回读有效参数」的通道
   （现有 `state/live.ts` 只有发布方向；回读需各工具 `apply` 回报，属跨 13 工具改动，按需再评估）。
   **M16 已做部分缓解**：对比页新增「实例自报指标（A / B）」表——取值被回退时指标不会随输入变化，
   把「值是否生效」变成可观察量（不改工具内部，只用既有的 `ToolApi.metrics()`；见《M16 验收单》§一/§五）。
2. 对象 / 数组类参数（如公式推导的自定义条目、框图的模型库）仍在工具页内编辑：对比页只对齐**标量**参数。
   其中「哪些键可调 / 用哪种控件 / 数值步长」的规则**已抽为纯函数** `state/params.ts`
   （`paramKind` / `scalarKeys` / `stepForValue`），并纳入固定门 `npm run uidata`（见《M13 验收单》）。
3. 文本参数提交时机为**失焦 / 回车**（原生 `change`），因此没有 Esc 还原语义（`NumField` 有）——为避免逐键重算而有意取舍。
4. 「重置为槽值」会把两侧全部参数恢复为槽保存值（含本次新增的标量与既有对象键）。
5. 其余已知边界见《M11 验收单》§五（残留 0.9% 的 Z 计数窗口）等。
