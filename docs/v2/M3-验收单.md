| 1 | 笔记若用 `setModuleState` 会顺手改写 `experiment.module` → 实验被记到不存在的工具名下（列出工具列显示 "notes"） | 新增 `setAuxState`（同样的自动保存，但**不改 module**）；模块级测试钉死该不变式 |

| 4 | `views.ts` 静态注册表阻止代码分割 | 删除 `views.ts`，改为 `tools/lazy.ts`（显式 loader 映射 + 缓存） |
| 5 | `core/pkg.ts` 与 `core/experiment.ts` 同时导出 `DecodeResult` → barrel `export *` 命名冲突（TS2308） | 内容包侧改名为 `PkgDecodeResult`；`PkgMeta.createdAt` 放宽为可选（打包时补齐），避免调用方构造负担 |
| 6 | 实验管理页缺分享码导出（M1 声称已交付但 UI 未接线） | 补齐「复制单实验分享码」（PX1）与「复制内容包分享码」（PK1），并给出超长降级说明 |
| 7 | A/B 若用 `setModuleState` 载入**不同工具**的槽，会把当前实验的归属 module 改写为该工具 | 载入时区分：同工具 → 写当前实验；不同工具 → `newExperiment` 新建，避免实验归属错乱 |
| 8 | A/B 缩略图若直接内联原尺寸 PNG，会击穿 32 KB/模块上限导致写盘失败 | 缩略图降采样为 ≤360 px JPEG(0.62)；序列化超限时**自动省略缩略图并说明原因**，槽本身仍保存成功 |
| 9 | **剧场的会话对象被原地变更**，`setState(getSession())` 传入同一引用 → Preact 跳过重渲染 → 暂停按钮点了没反应（状态仍显示「播放中」）；跳节之所以看起来正常，只是恰好被路由/重挂引发的重渲染掩盖 | 改为只保存自增版本号（`theaterRev`），渲染时 `getSession()` 现场读取 → 任何状态变化都刷新（含暂停/倍速） |

## 六、验收指引（所有者操作）

1. 本地启动：`cd v2 && npm run build && npm run preview` → http://localhost:5200
2. 走查顺序建议：
   - 打开首页（首屏应很快）→ 侧栏「系统分析」→ 观察右侧公式渲染（此时才加载 KaTeX 分片）；
   - 结果条点「图表 PNG」与「导出报告」→ 打开导出的 HTML 报告核对图表与指标；
   - 顶栏点「笔记」→ 输入内容 → 刷新页面 → 再次点「笔记」确认内容仍在；
   - 侧栏「设置中心」→ 切换主题与动效（观察页面即时变化）→ 「导出全部实验（JSON）」；
   - 侧栏「学习路径」→ 点某步「进入 →」跳转工具并自动完成该步；
   - 侧栏「实验管理」→ 勾选 2–3 个实验 → 「导出内容包 (.pkg)」→ 再从「导入内容包…」把该文件导入（或在页内粘贴 `PX1./PK1.` 分享码导入）；
   - 侧栏「系统分析」→ 调参 → 结果条「存 A」→ 换一组参数 → 「存 B」→ 点「对比」查看并排缩略图与差异表；
   - 侧栏「演示剧场」→ 点某剧本「▶ 播放」→ 在工作区底部旁白条上试 **暂停 / 下一节 / 2× / 退出**（观察每节自动切换工具与参数）；
   - 侧栏「交互求解」→「表达式」视图 → 点「🎙 语音输入 f(t)」口述一句（如「x 的平方 加 1」）→ 观察回填 `x^2+1`；
   - 侧栏「基线与契约」→ 查看符号登记表新增的「调制与通信」分组；「控件画廊」→ 查看「M3 新增控件与页级样式」区块。
3. 勾选本单「二、功能验收清单」；对未通过项填写复现步骤，修复后复验。
