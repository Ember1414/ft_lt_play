## 五、说明与遗留（移交后续）

1. **#7 结果层 warn/note（有意取舍）**：核心数值路径必须与 v1 逐字节一致（对拍网 77 组逐字段比对），
   向核心结果对象**新增字段会导致键集合不匹配而破坏基线**。因此极小分母兜底不在核心注入临时警告；
   已有显式退化输出（`note` / `ok:false`）保留在领域层；如需逐点「使用了兜底」提示，应在工具层
   基于输入病态性计算（属增强项，未纳入 M4）。
2. **`cvCol`**：v1 `plots.js` 的调色函数在 v2 已随图表层重写（`chart/` 令牌化配色），无同名实现，§四 第 6 项仅补 `niceStep`。
3. **`fft` 强校验**：内核仍沿用「调用方保证 2 的幂」约定（不加运行时抛错，避免改变库行为）；已由调用点零填充 + 注释约束。
4. **实时同屏曲线 A/B** 与 **剧场进阶**（参数插值）仍为可选增强，见《M3 验收单》§五。
5. **`nyquistFull.onCritical` 的采样限制** → **M11 已完成**：按本项建议在 (−1,0) 邻域自适应加密采样，
   并把虚轴直线段采样由 500 点提升到 5000 点；同根因导致的「刚越过临界增益的整段区间漏圈」也一并修正
   （详见《M11 验收单》§二/§四）。原描述保留如下：
   旧实现中 `onCritical` 以「采样点是否落在 (−1,0) 附近 `1e-6·scale`」判定，
   临界增益下曲线严格**相切** (−1,0)（如 G=K/(s+1)³ 的 K=8）未必被离散采样捕获 → 判为 `N=0、Z=0、stable=true`
   （闭环含虚轴极点，实为临界）。圈数 `N`/`Z` 本身与理论一致（#12 已交叉验证），仅该临界**标志**偏保守。
