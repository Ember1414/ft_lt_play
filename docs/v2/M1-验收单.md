## 二、功能验收清单

### 外壳（FR-01/02/08）
- [x] hash 路由（`#/tools/<id>`、`#exp=` 导入）与浏览器返回不丢输入
- [x] ⌘K 命令面板：21 个动作（13 工具 + 4 页面 + 4 动作）、最近动作置顶、↑↓/Enter/Esc、全键盘可达
- [x] 命令中心：继续实验卡（空态引导降级）、模板 8 个（禁用项给出原因）、学习路径占位（M3）、最近实验表
- [x] 实验管理：打开 / 收藏 / 复制 / 快照（新建 + 恢复）/ 删除（二次确认）
- [x] 存储不可用（隐私模式/配额）→ 顶部常驻提示 + 临时会话降级
- [x] 移动端（<1024）：底部标签栏、抽屉导航（遮罩/☰/Esc 关闭）、无横向溢出

### 系统分析（sys）
- [x] 波特图：对数轴（1/2/5 档位）、0 dB 穿越（金点）与 −180° 穿越（红点）标注、悬停读数、滚轮缩放/拖动平移/双击复位
- [x] 裕度：三阶案例 PM = 53.4°、ωc = 0.446、GM = 15.6 dB（与 v1 `modules/system.js` 算法逐行一致）
- [x] 奈奎斯特：G(jω) 轨迹 + (−1,0) 临界点 + P/N/Z 判据（K=20 → Z=2 不稳定）
- [x] 根轨迹：分支/渐近线/质心/虚轴穿越 K*=6.00@±j1.41（与 v1 测试基准一致）
- [x] 闭环阶跃（RK4），K 增大 → 发散振荡可观察
- [x] 零极点复平面（拖拽/缩放）、Mr/ωb/型别 ν/ess、稳定性三态（稳定/临界/不稳定）
- [x] 导出：CSV（波特数据）/ JSON（实验状态）；PNG 标「随报告系统 M2 交付」

### PID 整定（pid）
- [x] 环路仿真：P/PI/PID、执行器限幅、抗饱和（条件积分/反算）、微分先行、Tf 微分滤波、Ts 数字 PID、输入端扰动（阶跃/脉冲）
- [x] ZN 临界比例度：Ku = 6.000 / Tu = 4.443 / ωpc = 1.414（v1 基准案例）；一键应用 → Kp 3.60 / Ki 1.62 / Kd 2.00
- [x] FOPDT 两点法：对含积分环节对象正确拒绝（"末段未进入稳态"）
- [x] 分片寻优：进度实时（N 次仿真）、**可取消**、完成应用（ISE 1.656 → 1.275）；取消时参数不变
- [x] 指标：Mp / ts（±2% 带）/ ess / ISE / IAE / ITAE；导出 CSV（t,y,u,e）/ JSON

### Z 变换（z）
- [x] 单位圆：零极点（教材符号 ✕/○）、稳定域着色、ρmax/裕度、稳定/临界/不稳定三态
- [x] 频响：谐振器 cos(π/3·n) → 峰值在 ω = π/3（理论一致）
- [x] 序列 x[n]（n = 0…40；斜坡/指数/振荡）
- [x] Jury 判据：条件表（含"首项为负自动归一"）、特征表全行、临界文案（圆上极点）
- [x] s→z 三映射：冲激不变极点 0.9048 = e^(−0.1) 数值校验；ZOH / Tustin 系数表

### 全局行为
- [x] 自动保存（debounce）+ 刷新/直载恢复（渲染前恢复 + 实验切换重载）
- [x] 撤销/重做：⌘Z / ⌘⇧Z + 顶栏按钮；连续拖动合并为一次撤销点
- [x] 主题：浅色/深色/跟随系统；图表随主题重绘（含深色可读性验证）
- [x] reduced-motion：动效自动降级（令牌层约束）

## 四、缺陷记录（本里程碑发现并修复，共 10 项）

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | 工作区顶栏在"建设中"工具下不可达（撤销/实验名缺失） | 顶栏常驻（建设中工具亦显示） |
| 2 | 窄屏表格列被压到逐字换行 | 小屏横向滚动容器 |
| 3 | 工具数量文案 14 与注册表 13 不一致 | 统一为「13 个专业工具 + 命令中心」 |
| 4 | 命令面板默认只显示 12 项 | 取消截断（可滚动） |
| 5 | 刷新/直载不恢复实验参数（子组件 effect 先于父组件的时序问题） | 渲染前 `restoreLastSession()` + `useExperimentSync` |
| 6 | 稳定性文案把虚轴极点误判为"右半平面" | `poleClass` 三分（稳定/临界/不稳定） |
| 7 | 窄屏结果条 sticky 遮挡图表 | 窄屏回到文档流 + 指标横向滚动 |
| 8 | Jury 视图崩溃（`rows` 前两行为单元素数组） | 渲染守卫（内核 v1 结构保持不变） |
| 9 | s→z 表在宽屏被卡片裁切 | `.tbl.scroll` 容器 |
| 10 | Jury 临界文案与单位圆视图不一致 | 文案按 margin 三分 |
