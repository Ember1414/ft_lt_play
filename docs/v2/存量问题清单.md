## 五、迁移红线（回归网维护约定）

- 系数一律自高到低；复数一律 `{ re, im }`；`{ ok, ... }` / `{ ok:false, note }` 字段名与语义不得更改。
- 历史修正语义必须保留：`ltiResponse` 的 RK4 参数顺序修正、`polyRoots` 前导零剥离、`workerpool` 降级兜底（v2 由 Vite Worker 取代）。
- 任何内核改动后必须运行 `npm run parity`（v2），全部用例通过方可提交。
- 对拍网含「**闭式真值校验**」段（防 v1/v2 同错，见问题 21）：新增/修改解析式求值路径时，必须补对应闭式真值用例；真值用例只允许依赖数学闭式，不得引用任何一侧实现。
