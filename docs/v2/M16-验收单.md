# M16 验收单 · 实时双跑「两实例自报指标」对照（并顺带缓解 M12 §五 的取值回退盲区）

> 依据：M12 验收单 §五 第 1 项——「表格显示的是『你提交的值』，实际生效值由工具决定」这一盲区，
> 在不改动 13 个工具内部的前提下无法直接回读参数；本里程碑改为**让参数的实际效果可见**：
> 把两个并行实例各自上报的指标（`ToolApi.metrics()`）摆成 A/B 对照表。
> 交付 = 可运行版本 + 本验收单。版本 **2.11.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 指标采集 | `pages/Compare.tsx`：双跑两实例的 `api` 由「丢弃（`noopApi`）」改为**采集**——写入 `apisRef`（不触发重渲染），并在注册回调里读 `metrics()` 存入 `liveMetrics` |
| 采集时机（关键） | `metrics()` 是工具在 `useEffect` 里注册 api 时给出的**闭包**，随「参数/指标变化后重注册」才变新。因此必须在**注册回调里**读；在 rAF 里读会拿到上一轮闭包（滞后一轮）。此点在开发中被浏览器验证抓出并修正（见 §四 缺陷 1） |
| 去抖 | 以「指标签名」（label+value+unit 拼接）做守卫：无变化就不 setState → 不产生多余渲染，也避免注册回调引发的渲染回路 |
| 展示 | 双跑区块内新增「**实例自报指标（A / B · 随参数编辑实时刷新）**」表：指标 / 槽 A 实例 / 槽 B 实例 / 差（B−A，非零高亮），复用既有的 `metricDiff` / `fmtMetricVal`（与「槽指标对比表」同一套规则） |
| 与 M12 盲区的关系 | 表下方说明「若某参数取值不被工具接受，工具会回退默认，此时指标不会随你的输入变化」——**把「值是否生效」变成可观察量**（而非回读参数，后者需跨 13 工具改动） |
| 不影响既有行为 | 不改工具内部、不改分组覆盖通道、不改实验存储（双跑期间仍 `setSuppressSave`） |

## 二、功能验收清单

- [x] 双跑区块出现「实例自报指标（A / B · 随参数编辑实时刷新）」表；列 = 指标 / 槽 A 实例 / 槽 B 实例 / 差（B−A）
- [x] 两侧实例参数不同时数值确实不同、差列非零并高亮（实测：槽 A=K1 → PM **53.4 °**、槽 B=K4 → PM **11.4 °**、差 **−41.98**；GM 15.6/3.5 dB、ωc 0.446/1.143 rad/s）
- [x] **参数变化后表随实例刷新**：实测点「重置为槽值」（把两侧参数恢复为槽值）后，表立即回到 PM 53.4 / 11.4 / −41.98 —— 与槽 A=K1、槽 B=K4 一致
- [x] 指标为空（工具未上报）时不渲染该表（不出现空表噪声）
- [x] 换工具 / 换槽时清空旧指标（不留上一条对比的残值）
- [x] 边界保护：某工具的 `metrics()` 抛错时该侧记为空数组，不影响另一侧与页面
- [x] 浏览器实测零业务 console error（含临时诊断日志期间的复验）

## 四、缺陷记录

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | **自报指标滞后一轮**：指标最初在 rAF 链里读取（与对照曲线同一节拍），但 `metrics()` 是工具**被动 effect** 里注册的闭包，晚于绘制 → 参数变化后读到的是上一轮闭包，表格不刷新 | 改为**事件驱动**：在 api 注册回调里读并存入状态（并加签名守卫）。浏览器验证确认：参数变化 → 工具重注册 → 表随之刷新；点「重置为槽值」→ 表回到槽值对应数值 |

## 五、说明与遗留

1. **本轮把「不改工具内部」的原则守住了**：只用了各工具**既有**的 `ToolApi.metrics()` 契约（原本就被结果条使用，
   因此所有工具都会在参数变化后重注册以保持结果条新鲜）——这不是「回读参数」，而是「观察效果」。
   M12 §五 提出的真回读（拿到 sanitize 后的参数值）仍需要跨 13 工具改动，未做。
2. **测试环境注意（非产品缺陷）**：本项目浏览器走查所用的 WebView 里，**脚本化键盘输入不会真正提交**
   （输入框显示新值但应用状态未变，`NumField` 依赖失焦/回车提交）。本轮两次「表未刷新」的误报都由该现象造成；
   改用**只点按钮**的确定性路径（「重置为槽值」）即复现正确行为。真实浏览器里输入 + 失焦/回车会正常提交。
3. 移除临时诊断 `console.log` 后仅重跑质量门（该改动不含行为变化，故未重复浏览器走查）；
   移除后的产物与「加日志前」的构建**同名同体积**（`index-CmY3G9XQ.js` 175.60 kB），可作一致性佐证。
4. 指标对照表**只反映数值指标**；若某工具不上报指标，则该表不出现（各工具的指标口径见其 `metrics()` 实现）。
5. 其余已知边界见《M12 验收单》§五 与《M15 验收单》§五（开销门的敏感度）。
