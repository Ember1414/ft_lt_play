# M7 验收单 · 实时同屏双跑（对比页并行运行同一工具的两套参数）

> 依据：M5 验收单 §五 第 1 项「严格实时同屏 A/B」——此前为「保存时刻冻结的真实曲线叠加」；
> 本里程碑让对比页在**同一时刻并行运行两套参数**并给出**实时**对照曲线。
> 交付 = 可运行版本 + 本验收单。版本 **2.2.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 实例分组作用域 | 新增 `tools/group.ts`：`ToolGroupContext`（`''` = 工作区实例；对比页实例 `ab-a` / `ab-b`） |
| 覆盖通道加分组 | `state/live.ts`：`publishLiveOverride(group, toolId, params)`；订阅方按「组 + toolId」精确投递 |
| 同步钩子 | `tools/useSync.ts`：分组 ≠ `''` 的实例**不参与实验切换同步**，只接收本组覆盖 |
| 抑制写盘 | `state/experiments.ts`：`setSuppressSave(v)`——双实例挂载期间 `setModuleState`/`setAuxState`/`flushSave` 全部短路 |
| 图表分组 | `chart/Chart.tsx`：注册表记录分组，新增 `getSeriesByGroup(group)`；`getPrimarySeries()` 仅取默认组 |
| 对比页双跑 | `pages/Compare.tsx`：按需加载工具视图，两组各挂一个实例（`focus` 只留主内容），投递两槽参数并读回两条真实曲线做同屏叠加 |

**设计要点**：以「分组作用域 + 抑制写盘」实现**只读并行实例**，**不改动 13 个工具内部**——
工具照旧用 `useExperimentSync` / 自动保存，只是分组与抑制把它们隔离到对比页场景。

## 二、功能验收清单

- [x] `ToolGroupContext` 默认 `''`：工作区工具行为**完全不变**（剧场参数插值仍走 `''` 组，已回填 3 处调用）
- [x] 覆盖通道按「组 + toolId」投递：`ab-a` 组实例只收到 `ab-a` 的覆盖，互不串扰
- [x] 对比页实例不参与「实验切换同步」（`group !== ''` 时跳过订阅）
- [x] `setSuppressSave(true)` 期间：`setModuleState` / `setAuxState` / `flushSave` 均短路；离开对比页恢复
- [x] 对比页「实时同屏双跑」区块：同工具 + 两槽齐备时出现；含**实时对照图**（A 洋红实线 / B 青虚线，范围取并集）
- [x] 区块下方左右并排「槽 A 实时」「槽 B 实时」两张卡，各挂载该工具一个**只读实例**（只显示主内容）
- [x] 加载失败/未知工具时优雅降级（不出区块，不影响对比页其余内容）
- [x] **浏览器实测**：`sys` 存 A → 切结构模板 → 存 B → 页内「对比」→「实时同屏双跑」出现实时对照曲线 +
      两个并行实例画面；布局正常（无错位/溢出/空白）；**零 console error**

## 四、缺陷记录

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | 双实例与工作区实例 toolId 相同 → 实时覆盖与实验同步会互相串扰；工具自动保存还会污染当前实验 | 引入**分组作用域**（覆盖按「组 + toolId」投递、分组实例跳过实验同步）+ `setSuppressSave` 抑制写盘 |
| 2 | `getPrimarySeries()` 若把对比页实例的图也算进「主图」，会污染工作区 A/B 存槽采集 | `getPrimarySeries()` 改为只取默认组（`''`）；对比页按组取图 |

## 五、说明与遗留

1. **实时双跑参数已可调** → **M8 已完成**：对比页新增可调参数表（数值键并集，A / B 双输入框），编辑即实时重算两实例与对照曲线（见《M8 验收单》）。
2. 双实例会**各跑一遍工具计算**（含各自动画），对重动画工具（如 `ft` 画圈）有一定开销——仅在进入对比页时发生。
3. 未要求同一工具：不同工具时不出「实时双跑」区块（仅并排槽卡与指标/参数差异）。
4. 其余已知边界（`onCritical` 采样）见《M4 验收单》§五；**剧场脚本编辑 → M9 已完成**（自建剧本库 + `TS1.…` 分享码，见《M9 验收单》）。
