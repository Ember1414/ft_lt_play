# M18 验收单 · 坐标图交互质量（缩放边界 / 刻度动态 / 数值与图间重合）

> 依据：用户要求「检查各坐标图边界是否能随意缩放、坐标上的分度值能否随意动态变化、坐标数值是否有重合、
> 各坐标图是否有重合」。核对后确认**共享图表层**存在 4 处真实缺陷（均有可复现证据），本里程碑一并修复，
> 并把规则锁进第 ⑤ 组 UI 数据层断言。交付 = 可运行版本 + 本验收单。版本 **2.13.0**。

## 一、缺陷清单与本轮处置（先取证，再修复）

| # | 缺陷 | 证据 | 处置 |
|---|---|---|---|
| 1 | **刻度数值重合（深缩放）**：默认刻度格式 `fmtTick` 固定 4 位有效，深度缩放后相邻刻度被四舍五入成同一个数 | 探针实测：`0.3000002 / 0.3000004 / 0.3000006`（步长 2e-7）→ 三者都格式化为 `"0.3"` | 新增**步长自适应**格式 `fmtTickAt(v, step)`：小数位由刻度步长决定；`drawFrame` 改用之（大/小量走指数，位数由「步长/数值」相对量级决定） |
| 2 | **刻度数值重合（中等缩放）**：`z` 工具对线性频率轴硬编码 `toFixed(2)`，缩放后重复 | 探针实测：相位轴 `toFixed(2)` 在跨度 0.02 rad 时多个刻度显示 `"0.00"` | `z` 的两处 `xTickFmt` 改为 `fmtTickAt(v, step)`（保留 `0` / `π` 特判）；`xTickFmt` 签名增加第二参数 `step` |
| 3 | **坐标数值与 y 轴标题重叠 / 被左缘裁剪**：`MARGIN.l=46` 固定，y 数值右对齐于轴左 6px、y 标题固定在轴左 30px，数值宽于 ~19px 即压住标题；窄边距复平面上标题半截出画布 | 相位图 y 数值 `-180 / -250`（宽 ≈33px）→ 与旋转标题「相位 (°)」重叠 | `drawFrame` 改为：先量测 y 数值最大宽度，把 y 标题摆到**数值左侧**（`rect.x - 8 - maxYW - 12`）；`Chart`/`ComplexPlane` 的**左边距按实测宽度动态放宽**（`max(基准, 数值宽 + 8 + 12 + 16)`） |
| 4 | **x 轴数值相撞（窄图）**：`drawFrame` 画出每个刻度标签、无重叠判定，窄画布上相邻标签叠在一起 | 窄图（rect.w≈160，3 刻度约 53px 间距）配长标签（如指数形式）→ 相撞 | `drawFrame` 增加**像素级重叠跳过**：标签左缘与上一个已画标签右缘间距 < 6px 则跳过该标签 |

附带修复（同一根因）：

| # | 缺陷 | 处置 |
|---|---|---|
| 5 | **缩放可退化**：`Chart` 滚轮缩放无跨度保护，极限缩放下跨度趋 0（浮点不可分辨）或放大到无意义尺度 | 新增纯函数 `clampSpan(range, base, 1e-6, 1e6)`：把可视跨度限制在基准跨度的 [1e-6, 1e6] 倍内；非法/塌陷区间回退基准并保留中心。**正常缩放不受影响**（原样返回） |

> 说明：`ComplexPlane` 的缩放此前已有 `[0.25, 8]` 限位，无需改动；本轮只补齐其**左边距**（缺陷 3）。

## 二、功能验收清单

- [x] 缩放后刻度分度值**动态变化**且相邻刻度**永不重复**（步长自适应格式；`uidata` ⑥ 项断言逐档验证）
- [x] 工具自定义刻度格式（`z`）同样随缩放自适应，不再出现重复数值
- [x] y 轴数值与 y 轴标题不再重叠、不再被画布左缘裁剪（动态左边距）
- [x] x 轴数值在窄图下不再相撞（像素级重叠跳过）
- [x] 缩放不会退化为无意义尺度或浮点不可分辨（`clampSpan` 保护）
- [x] 正常量级区间原样返回、不干扰既有缩放体验（`clampSpan` 返回原区间）
- [x] 各坐标图为独立容器、各自留白，**图间不重合**（13 个工具走查无图叠加/越界；本轮仅动左内边距）
- [x] 浏览器实测零业务 console error

## 四、说明与遗留

1. **改动集中在共享图表层**（`chart/canvas.ts`、`chart/Chart.tsx`、`chart/ComplexPlane.tsx`）与 `z` 工具的两处格式器；
   13 个工具的图表**全部受益**，无需逐个改。未改内核（parity/audit 维持）。
2. `fmtTick`（固定 4 位有效）**保留**，用于对数轴刻度与悬停读数；新逻辑只在**线性轴且能确定步长**时启用，
   因此对数轴（如控制系统的波特频率轴）行为不变。
3. 浏览器实测（单并发，零业务 console error）：
   - `系统分析`：幅值轴 y 数值 `40/20/0/-20/-40/-60/-80`、相位轴 `0/-50/-100/-150/-200/-250`，
     标题「幅值 (dB)」「相位 (°)」清晰未被压住；x 轴 `0.01 … 1000` 清晰不撞。
   - `Z 变换`（单位圆）：y 数值 `2/1.5/1/0.5/0/-0.5/-1/-1.5/-2`、标题「Im」清晰、x 轴 `-2/-1/0/1/2` 不撞。
   - `拉普拉斯` 复平面本轮因自动化环境 WebView 争用两次阻塞（**环境现象，非缺陷**）；
     因其与 `Z 变换` 共用同一 `ComplexPlane` 组件，同日组件已在 `Z 变换` 页验证。
4. 遗留（可选增强）：`Chart` 的**平移**仍不设边界（可把图拖出视野），但双击复位可恢复（工具提示已注明）；
   `ComplexPlane` 无复位手势（双击=新增极零点），如需「一键取景」可后续补按钮。
