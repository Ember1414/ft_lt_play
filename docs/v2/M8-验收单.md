# M8 验收单 · 可调参实时双跑（对比页直接调参、A/B 即时重算）

> 依据：M7 验收单 §五 第 1 项——M7 的并行实例为「只读」（参数取自槽），本里程碑让**参数可在对比页直接调**，
> 两个实例与对照曲线**实时**响应。
> 交付 = 可运行版本 + 本验收单。版本 **2.3.0**。

## 一、交付范围

| 项 | 内容 |
|---|---|
| 可调参数表 | `pages/Compare.tsx`：实时双跑区块新增「参数（可直接调 · A / B 双跑实时响应）」——取两槽参数的**数值键并集**，每行「槽 A / 槽 B」两个 `NumField`（步长/精度按量级自适应） |
| 实时重投 | 编辑即更新本地参数 → 经分组覆盖通道重投 `ab-a` / `ab-b` 两实例 → 实例画面与对照曲线**实时**刷新 |
| 不写回存储 | 沿用 M7 的 `setSuppressSave`——编辑仅作用于本页双跑实例，**不污染当前实验** |
| 重置 | 「重置为槽值」：把可调参数恢复为槽 A / 槽 B 保存时的值 |
| 槽变化重载 | 槽 `savedAt` 或工具变化 → 可调参数自动重置为槽值 |

## 二、功能验收清单

- [x] 可调键 = 两侧参数的**数值键并集**（非数值键不展示；无数值键时给出说明而非空白）
- [x] 每行两个 `NumField`，`step`/`precision` 按量级自适应（≥100→1/1、≥10→0.1/2、≥1→0.01/3、≥0.1→0.001/4、否则 0.0001/5）
- [x] 编辑「槽 B」某参数 → 该侧实例与对照曲线**即时**变化（对照读图在 `rAF → rAF` 后取回）
- [x] 「重置为槽值」→ 参数恢复为槽保存值
- [x] 编辑不写回实验存储（`setSuppressSave` 覆盖期生效）
- [x] **浏览器实测**：`sys` 存 A → 切结构模板 → 存 B → 页内「对比」→ 参数表存在（双输入框 + ⇔ 拖动把手）→
      把槽 B 的 `K` 由 **1.000 改为 3.000** → 槽 B 实时波特图随之变化 → 「重置为槽值」恢复为 **1.000**；
      页面滚动正常、内容无截断、**无业务 console error**
