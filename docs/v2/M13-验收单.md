# M13 验收单 · UI 数据层断言并入 CI（把临时断言变成可回归的门）

> 依据：M9 验收单 §五 第 4 项、M10 验收单 §五 第 2 项、M12 验收单 §五（浏览器一次性验证）——

## 二、功能验收清单（61 条断言分组）

- [x] **M9 剧本库编解码（26 条）**：`TS1.` 三段往返逐字段一致；`.json` 通道往返；篡改一位→校验失败；
      错前缀 / 非码非 JSON / 空输入各有具体原因；内置 id（`t-`）解码后重分配为自建 id；
      无名称 / 无步骤被拒；空 `toolId` 步丢弃；`dwell` 越界夹到 300ms；超限参数丢弃；
      增删查与计数（`getAllScripts` / `getUserScripts` / `isUserScript` / `getScript` / `clearUserScripts`）；超长分享码抛 `too-large`
- [x] **M10 备份数据通路（22 条）**：`buildBackup → JSON → readBackup` 往返一致；旧包（无 `theaterScripts`）→ `null`；
      历史单实验文件 → `[root]`；非法 JSON → 具体原因；剧本恢复幂等覆盖（重复导入数量不变）；
      混合包（合法 1 + 非法 2）逐项计数不影响合法项
- [x] **M12 参数表规则（13 条）**：`paramKind` 对有限数 / NaN·Infinity / 布尔 / 字符串（含空串）/ null·undefined / 对象·数组 的分派；
      `scalarKeys` 标量并集 + 字典序排序 + 排除对象·null·NaN + 空参兜底 + 跨对象合并；
      `stepForValue` 五档量级（≥100 / ≥10 / ≥1 / ≥0.1 / 其余）+ 负数按绝对值
- [x] **门确实会红（本轮做了变异验证）**：临时把 `paramKind` 改成「对象也返回 `boolean`」→
      `npm run uidata` 立即以 **58/61 + 退出码 1** 报出 3 条失败（对象·数组、并集、排除规则），随后还原 → 61/61
- [x] **页面行为无回归（浏览器实测，零业务 console error）**：对比页参数表仍为 **expr / K / view** 三行

## 五、说明与遗留

1. **责任边界**：`parity.mjs`（v1↔v2 数值）、`audit.mjs`（内核语义/闭式）只覆盖 `src/core`；
   `uidata.mjs` 覆盖内核之外的**纯数据逻辑**（剧本库 / 备份包 / 参数表规则）。
   三者都不覆盖 JSX 渲染与交互——那部分仍靠里程碑的**浏览器走查**（见各验收单），CI 不跑浏览器。
2. `state/params.ts` 只承载「规则」，页面保留「渲染」：`ParamCell` 仍按 `paramKind` 分派控件、
   文本提交仍走原生 `change`（失焦 / 回车）——M12 §五 的取舍（无 Esc 还原、无效值由工具回退）不变。
3. 断言脚本用 `platform: neutral` 打包 + localStorage 桩；若后续引入别的浏览器全局依赖，
   需在同一处补桩（脚本头部已集中列出桩替身）。
4. 依赖 `esbuild` 由 `vite` 传递提供（与 `parity.mjs` / `audit.mjs` 一致），未新增直接依赖。
5. 其余已知边界见《M11 验收单》§五（残留 0.9% 的 Z 计数窗口）与《M12 验收单》§五（实例回读通道）。
