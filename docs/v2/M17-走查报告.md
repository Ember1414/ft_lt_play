## 三、对比页数据表：验证方式与证据链（环境受限说明）

对比页的「可调参数表」「实例自报指标表」「重置为槽值」按钮**按设计只在该页存在 A / B 两槽数据时渲染**
（无槽数据时为引导空态）。本轮尝试用「工具页 → 存 A → 存 B → 对比」的纯点击流把数据表验出来，
但该流程在两次尝试中均被浏览器自动化环境的 WebView 争用阻塞（见 §四），未能取得运行时快照。

因此对这三项采用**证据链**判定其在位，而非运行时点击流：

1. **源码在位**：`src/pages/Compare.tsx` 含「实例自报指标（A / B · 随参数编辑实时刷新）」表头、
   「重置为槽值」按钮与可调参数表渲染分支（[Compare.tsx](file:///e:/Projects/ft_lt_play/v2/src/pages/Compare.tsx)）。
2. **CI 断言锁定**：`npm run uidata` 第 ④ 组「指标对照规则（M16）」**13 条**断言（行序 / 数值差 /
   单侧缺失不臆造 0 / 字符串值 / 空表 / 同值为 0 / 单位回退 / 显示格式化），已并入 CI。
3. **上一里程碑运行时实测**：M16 验收单 §二/§四记录了真实浏览器实测
   （槽 A=K1 / 槽 B=K4 → PM 53.4 ° / 11.4 ° / −41.98 等，且点「重置为槽值」后表随之刷新）。
4. **本轮空态**：对比页空态渲染正常、**0 error**，说明页面外壳（路由 / 布局 / 空态文案）无回归。

## 四、环境说明（非缺陷）——WebView 争用导致「伪 BLOCKED」

本轮并行启动多个浏览器走查会话（每会话 3 个 URL）时，**部分会话对 localhost 页面反复报
「WebView is not ready yet / IDE Command timeout」**，表现为整页无法取快照（伪 BLOCKED）。
处置：**降为单并发重试**——被阻塞的 `实验管理`、`交互求解 / 随机信号 / 调制与通信`、`演示剧场` 等页
在单并发下均**一次性通过**（正常渲染、0 error）。

结论：该现象是**自动化环境的并发争用**，与页面本身无关，**不是产品缺陷**；后续 browser_use 走查一律**单并发**。

另有两次尝试失败源于**预览服务被中断（chrome-error）**，亦属环境现象。
