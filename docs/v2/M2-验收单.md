## 二、功能验收清单

### 存量迁移工具（9 个）
- [x] 傅立叶级数：画圈动画（时间轴引擎）· 手绘 DrawPad · 谐波叠加（含实测 Gibbs 过冲）· 瀑布投影 · 级数/谐波 SVG 导出；（v1「手绘画圈」页签并入此工具，去重）
- [x] 傅立叶变换：时频联动 · 卷积动画（面积填充 + 时间光标 + 顶点慢镜头）· Parseval 入结果条 · 混叠折叠动画 · 谱域互验 `specErr`
- [x] 拉普拉斯变换：s 平面零极点 · ROC 遮罩 · 留数散点互验 · 多 ROC 条带 · 定义积分自检 · 性质验证
- [x] Z 变换（M1）：单位圆 / 频响 / 序列 / Jury / s→z 五视图
- [x] 系统框图：SVG 编辑器 · 正交避障布线 · 传函求解 · 采样系统 z 域分析（求和点单位增益 + 误差点采样拓扑）
- [x] 交互求解：表达式 / 微分方程（解析散点互验）/ 差分方程 / 数据与滤波 / 符号变换 五视图
- [x] 公式推导：性质表（ft/la/lt/zt/ztp）× 逐步推导（5 条）× 自定义推导（逐项 + 定义积分自检）

### 滤波器设计器（filter，新增）
- [x] IIR：Butterworth / Chebyshev I / Chebyshev II × 低通/高通；阶数由规格自动估计（≥上限给出提示）
- [x] 幅频（含规格掩膜 −Rp/−Rs 条与 fp/fstop 实测点）/ 相频 / 群时延
- [x] 零极点：数字（单位圆，稳定性三态）+ 模拟原型（s 平面）
- [x] 系数量化对比（4–24 bit，最大频响偏差读数，量化后 b/a）
- [x] 时域：脉冲响应 / 阶跃响应（差分方程）
- [x] FIR：窗函数法（矩形/Hamming/Hanning/Blackman）+ 四窗同图对比 + 冲激响应 + 线性相位群时延
- [x] 导出：系数 CSV / 设计 JSON / 一键「交接系统分析」（写入 sys 实验并跳转）

### 控制系统设计器（control，新增）
- [x] 对象分析：G(s) 解析 + 预设 · 波特（校正对比虚线）· 闭环阶跃 · Mr/ωb · 零极点（含校正器零极点）
- [x] 超前校正：目标 PM + ωm → C(s)=Kc(s+z)/(s+p)，实测达 PM（案例 1/(s(s+1))、ωm=2、PM=50° → 达成 50.00°，ωc=2.00）
- [x] 滞后校正：新穿越频率 ωc′ + β，实测 PM 提升（51.8° → 58.0°）
- [x] 极点配置：ζ、ωn 期望极点 → 可控标准型 + Ackermann → K；闭环极点与 T(0)/前置增益提示
- [x] 灵敏度校核：|S|、|T| 曲线 + Ms 峰值三态判定
- [x] 导出：校正器 CSV / 设计 JSON / 交接系统分析

### 随机信号实验室（random，新增）
- [x] 噪声源：高斯/均匀/正弦+噪声；确定性 seed（可复现，可「换一组/恢复默认」）
- [x] 时域 + 直方图 + 统计量（实测 vs 理论方差）
- [x] 功率谱密度：周期图 vs Welch 分段平均（窗函数、段长可选）+ Parseval 说明
- [x] 相关分析：自相关 Rxx(k) / 互相关 Rxy(k)（与同频正弦）
- [x] 滤波对比：一阶 IIR 前后时域 / PSD / 自相关 + 输出方差理论式

### 调制与通信实验室（comm，新增）
- [x] AM（调制度 m，过调幅提示）+ 包络（解析信号）+ 频谱（载波 + 双边带，边带比 m/2）

## 四、缺陷记录（本里程碑发现并修复）

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | 留数解析求值共轭极点组漏乘 2（v1/v2 同错，对拍网无法发现） | v1/v2 同步 ×2 修正 + 闭式真值钉（详见存量清单 #21） |
| 2 | 系统框图求和点未带单位增益 → 求解得到开环而非闭环 | 新增 `UNIT_FRAC`，示例/sanitize/addNode 三处补齐；闭环极点与理论吻合 |
| 3 | 采样示例拓扑错误（含未被采样的连续元件） | 改为「误差点采样 → ZOH → G(s)」标准接法；z 域闭环极点 e^{−T}−2(1−e^{−T}) 吻合 |
| 4 | 滤波器设计内核 5 处偏差点（预畸变 2/T、LP 缩放指数、Chebyshev I 增益归一、Chebyshev II 极点/阶数、高通补零） | 逐条修正，由真值钉定位（详见存量清单 #23） |
| 5 | `chartColors` 的 `var(--series-N)` 在 Canvas 中无效（曲线颜色实际未生效） | 新增 `resolveColor()`，drawLine/drawMarkers 统一解析 |
| 6 | `.chip` 无样式（裸类名） | 统一改为 `.btn` + `is-on` |
| 7 | 结果条显示原始 LaTeX + 小量显示为 0.00 | 纯文本 ROC + 小量科学计数（详见存量清单 #22） |
| 8 | KaTeX 类型不兼容（`window.katex` 赋值、`Record<string,unknown>`） | 断言/放宽类型 |
| 9 | 控制系统闭环指标误把「闭环传函」当开环喂给 `closedLoopMetrics` | 改为传开环 L；极点配置视图改用本地闭环 T 指标（含 T(0)/前置增益提示） |
| 10 | 路径进度与实验状态耦合会互相污染 | 进度独立持久化（`v2:paths:progress`），与实验数据解耦 |

## 六、验收指引（所有者操作）

1. 本地启动：`cd v2 && npm run build && npm run preview` → 打开 http://localhost:5200
2. 建议走查顺序：
   - 首页 → 模板「Butterworth 低通」→ 滤波器页看幅频/零极点/量化/FIR；
   - 侧栏「控制系统设计器」→ 切「超前校正」看校正前后波特与 PM 达成；
   - 侧栏「随机信号实验室」→「功率谱密度」看周期图 vs Welch；
   - 侧栏「调制与通信实验室」→「采样定理」调 fs 观察混叠、再切「眼图」；
   - 顶栏「学习路径」→ 点第 1 步编号圆圈看进度；点「进入 →」跳转工具并自动完成；
   - 刷新页面确认实验与路径进度均恢复。
3. 勾选本单「二、功能验收清单」；对未通过项填写复现步骤，修复后复验。
